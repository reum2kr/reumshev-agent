## 6. 지원 범위와 미해결 사항

- 지원: Windows + PowerShell, Node.js 24.x(실제 확인 v24.22.0), 브라우저 `http://127.0.0.1:<포트>`.
- 미확인: Node.js 24.19.0 정확한 버전, macOS·Linux, 새 폴더에서의 종료·재실행·예제 모드·도움정보 복사·패키지 조회.
- 미해결(연결 없음): 실제 회사 시스템(SDP) 연결, 앱 안 AI 실제 연결·사건 설명, 실제 조치 집행(19단계 실집행 미준비), OSV 실제 패키지 조회 결과.
- 22단계 판정은 원문 검토 기준의 수료이며 실제 운영 인증이나 v1.0 인증이 아닙니다.
