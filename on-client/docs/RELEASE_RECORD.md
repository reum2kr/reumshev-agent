### 무엇을 더했나 (직접 만든 부분)

`student/extension.mjs`의 「보호 현황」 학생 칸(`renderStatus`) 아래에 **「연결과 기록(읽기 전용)」** 묶음을 추가했습니다.

| 줄 | 읽는 곳 | 표시 |
|---|---|---|
| 네트워크 연결 | 「PC 조회」 버튼 → `api.get('/api/pc/status')` 한 번 | 응답이 있으면 [실측] 응답 받음. 세부 형식은 참고 문서에 없어 해석하지 않고 제공 카드 「내 PC 상태」로 안내 |
| 방화벽 설정 | 같은 조회의 `firewall.profiles`(Domain·Private·Public) | [실측] 프로필별 켜짐/꺼짐 · 읽기만 함 · 켜짐이 안전 판정은 아님 |
| Windows 경고·오류 | 같은 조회의 `events`(System·Application) | [실측] 경고 n건 · 오류 n건 · **침해·공격 탐지 결과가 아님**. 일부 집계면 그 한계를 함께 표시 |
| SDP 서버 | PC 조회와 **별도로**, 기존 상태 입력(`mode`, 기기·세션 오류 코드, 알림 코드) | `ENGINE_NOT_CONNECTED`면 「SDP 미연결」. 예제 서버면 「SDP 미연결 · 예제 서버 응답」 |

- 「확인 불가」에는 항상 이유를 붙입니다. 이유는 앱 판 미지원(`NOT_ALLOWED`), 응답 형식 불일치, 조회 실패, 오래된 응답(60초 초과), 항목 없음, 권한 부족 중 하나입니다.
- 권한 부족 항목은 권한을 바꾸지 않고 「확인 불가 · 권한 부족」으로 남깁니다.
- 「예시 보기」를 누를 때만 카드의 설명용 값이 **[예시]** 표시와 함께 따로 나옵니다. 실측 줄과 섞이지 않습니다.
- 읽기 전용입니다. 방화벽·보안 설정 변경, 관리자 권한 요청, 자동 반복 조회, 공격·침투 흉내 시험이 없습니다.

### 현재 한계 (정직한 상태)

- 이 저장소의 시작 틀은 **0.2.11**입니다. `/api/pc/status` 경로와 제공 카드 「내 PC 상태」가 없고, 학생 API 허용 목록에도 이 경로가 없습니다.
- 그래서 지금 앱에서는 「PC 조회 확인 불가 · … 허용하지 않음 [NOT_ALLOWED]」가 나오는 것이 **정상**입니다. 실측값은 아직 0개입니다.
- 학생 코드도 이 경로를 읽을 수 있는 0.2.18이 적용되면, 코드를 바꾸지 않고 실측이 표시되도록 만들었습니다. 이는 합성 응답으로만 시험했습니다(아래).
- 실제 학생 PC에서 받은 실측 결과는 **미확인**입니다.

### 실행 명령과 확인 순서 (Windows PowerShell)

```powershell
cd C:\Users\<사용자>\Documents\GitHub\reumshev-agent\on-client
node --version
powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1
```

1. 브라우저에서 `http://127.0.0.1:5189/`를 열고 「보호 현황」으로 갑니다. 학생 칸 맨 아래에 「연결과 기록(읽기 전용)」이 있습니다.
2. 처음 상태를 확인합니다. 「PC 조회 전」이 보이고, 세 줄 모두 「조회 전」입니다.
3. 「SDP 서버(PC 조회와 별개)」 줄에 「SDP 미연결 [ENGINE_NOT_CONNECTED]」가 보이는지 확인합니다.
4. 「PC 조회(한 번 읽기)」를 누릅니다. 0.2.11에서는 「PC 조회 확인 불가 … [NOT_ALLOWED] · 조회 <시각>」이 나오고, 세 줄이 「확인 불가 · PC 조회 결과 없음」으로 바뀝니다.
5. 「예시 보기(설명용 값)」를 누릅니다. **[예시]** 표시가 붙은 별도 상자가 나오는지 확인합니다. 다시 누르면 숨겨집니다.
6. 창에서 Ctrl+C로 앱을 끕니다.
7. (선택) 같은 명령 끝에 ` -Demo`를 붙여 실행합니다. SDP 줄이 「SDP 미연결 · 예제 서버 응답(실제 연결 아님)」으로 바뀌는지 봅니다.
