- 직접 확인한 것만 「확인함」으로 적고, 확인하지 않은 것은 「미확인」, 읽지 못한 값은 「확인 불가」로 남깁니다.

## 0. 시연 순서 (실제 연결 모드, 약 3분)

준비: `on-client` 폴더에서 PowerShell(터미널)을 열고 아래 한 줄을 입력합니다.

    powershell -NoProfile -ExecutionPolicy Bypass -File .\tools\start-alekov.ps1

| 순서 | 할 일 | 화면에서 보여 줄 것 (실제로 나오는 것) | 확인 |
|---|---|---|---|
| 1 | 앱 켜기 | PowerShell에 「케셰브가 켜졌습니다 …」 등 정상 시작 신호. 「참고: Node.js …」 줄은 버전 안내라 정상 | 확인함(PC) |
| 2 | 브라우저 `http://127.0.0.1:5189/` → 「보호 현황」 | 학생 칸 맨 위 「름셰브 핵심 3가지」. 「아직 조회하지 않았습니다」, 세 줄 「조회 전」, 「SDP 미연결 [ENGINE_NOT_CONNECTED] · 앱 첫 화면 자료 기준」 | 확인함(PC) |
| 3 | Tab으로 「다시 조회」까지 가서 Enter | ① 「PC 확인 불가(지원 없음) [NOT_ALLOWED]」와 세 줄 「확인 불가」, ② 「SDP 미연결 [ENGINE_NOT_CONNECTED] · 확인 <시각>」, 「읽지 못한 항목과 다음에 할 일」 2줄(예시 값으로 채우지 않음) | 확인함(PC) |
| 4 | 초점이 남은 채 Enter 한 번 더 | ③ 조회 기록 2건(최신이 위), 초점이 「다시 조회」에 유지됨 | 확인함(PC) |
| 5 | Tab으로 「[예시] 설명용 값 보기」 → Enter | [예시] 표시가 붙은 네 줄이 따로 펼쳐짐. 위의 실제 조회 줄은 바뀌지 않음 | 확인함(PC) |
| 6 | 화면 맨 위 빨간 상자 설명 | `[ENGINE_NOT_CONNECTED]` 칸 여러 개 = 회사 시스템(SDP) 미연결. 앱 고장이 아니며, 숨기지 않고 그대로 보여 줌 | 확인함(PC) |

### 핵심 기능 1 · 내 PC 연결과 기록 (네트워크 · 방화벽 · Windows 경고·오류)

- **제공된 부분:** 학생 API `api.get`. PC 값을 읽는 `/api/pc/status`는 0.2.18부터 학생 코드에 허용될 예정이라, 지금 판에는 없습니다.
- **내가 직접 개선한 부분:**
  - 「다시 조회」를 누를 때만 한 번 읽습니다.
  - 항목마다 [실측]과 잰 시각, 또는 「확인 불가」와 이유를 붙입니다.
  - 방화벽은 「읽기만 함 · 켜짐이 안전 판정은 아님」으로 표시합니다.
  - Windows 경고·오류에는 「침해·공격 탐지 결과가 아님」을 붙입니다.
  - 권한 부족이면 「권한을 바꾸지 않음」이라고 적습니다.
  - 응답이 60초를 넘으면 오래된 값으로 보고 현재 값으로 쓰지 않습니다.
- **실제 확인 결과:** 확인함(PC). 0.2.11에서 「PC 확인 불가(지원 없음) [NOT_ALLOWED]」와 세 줄 「확인 불가」가 나옵니다. **실측값은 0개입니다.**
- **잘못된 입력이나 연결 실패 때의 동작:**
  - 확인함(PC): NOT_ALLOWED이면 「읽지 못한 항목」에 다음 할 일(0.2.18 적용 뒤 다시 조회)이 나옵니다.
  - 확인함(모의): 조회 실패(TIMEOUT), 형식 불일치, 권한 부족(ACCESS_DENIED), 항목 없음.

- **제공된 부분:** `/api/me` 응답과 그 `meta.mode`, 앱이 넘겨 주는 연결 상태와 알림 코드, SDP 어댑터.

## 3. 값의 종류 구분

- **실제 조회:**
  - PC 실측은 **0개**입니다(0.2.11에서 `/api/pc/status` NOT_ALLOWED).
  - 실제로 읽은 것은 서버 응답 상태뿐입니다. NOT_ALLOWED와 ENGINE_NOT_CONNECTED 코드, 그리고 그때 우리 화면이 기록한 조회 시각입니다.
- **설명용 예시:** 「[예시] 설명용 값 보기」 안의 네 줄(유선 연결됨, 켜짐 · 읽기만 함, 경고 3건 · 오류 0건, SDP 미연결)입니다. 펼칠 때만 [예시] 표시와 함께 보이며, 실패 화면을 채우는 데 쓰지 않습니다.
- **미연결:** SDP(로그인 정보, 업무 앱, 보안 기록, 기기, 세션), 앱 안 AI, 조치 집행.
- **확인 불가:** 네트워크, 방화벽, Windows 경고·오류. 이유는 「이 앱 판은 학생 코드의 PC 조회를 허용하지 않음 [NOT_ALLOWED]」입니다.
